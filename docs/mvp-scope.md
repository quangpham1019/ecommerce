# MVP Scope

## In scope

- Customer registration and login
- Product catalog and category browsing
- Search and filter basics
- Cart management
- Checkout flow
- Order placement
- Payment integration with one provider
- Inventory tracking
- Admin product and order management
- Basic transactional notifications

## Out of scope

- Seller onboarding and marketplace commissions
- Recommendation engine
- Returns automation
- Promotions engine v2
- Rich analytics and BI
- Dedicated mobile apps

## Release principle

Each release should improve one complete user workflow. No release should contain only infrastructure or only backend plumbing unless it directly unblocks the next visible slice.
