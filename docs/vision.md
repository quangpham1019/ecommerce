# Vision

## Product goal

Build a production-minded ecommerce platform that supports the essential customer purchase journey and the basic internal operations required to run an online store.

## Target users

- Shoppers who want to browse products, compare options, add items to cart, and complete checkout reliably
- Store operators who need to manage products, inventory, and order fulfillment
- The solo developer who needs clean module boundaries, low operational complexity, and safe iterative delivery

## Problem statement

Many ecommerce systems become complex too early. This project aims to prove that a well-structured modular monolith can support meaningful business capabilities without incurring premature microservice overhead.

## Success criteria for MVP

- Customer can register, browse products, add items to cart, and place an order
- Admin can create products, adjust inventory, and manage order status
- Application can be deployed to AWS with a repeatable and documented process

## Non-goals for MVP

- Multi-vendor marketplace workflows
- Personalized recommendation engine
- Real-time chat, wishlists, or loyalty systems
- Global multi-region architecture
